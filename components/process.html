My Design Process

I follow a structured, iterative design methodology centered on human needs and empirical feedback loops.

1

Empathize

Observe and interview target users in their environment to map out real frustrations.

2

Research

Collect quantitative surveys and analyze competitors to build a research baseline.

3

Define

Create user personas and user journey maps to formulate the core problem statement.

4

Ideate

Brainstorm user flows, information architectures, and creative layout structures.

5

Wireframe

Build low-fidelity interactive blocks in Figma to test spatial hierarchy rapidly.

6

Prototype

Design high-fidelity component UI and create clickable micro-interactive prototypes.

7

Test

Run task-based usability testing sessions to isolate UI gaps and friction points.

8

Iterate

Refine typography, layout, and copy details recursively until user metrics align.
